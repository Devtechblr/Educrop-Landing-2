# Educrop – Modern Connected Classroom Website

A modern, premium-looking website developed for **Educrop**, using the Teachmint X reference design as the exact visual specification.

## Features Implemented
- **100% Brand Replacement**: Replaced all references from Teachmint / Teachmint X to Educrop / Educrop X.
- **Top Announcement Bar**: Full-width dark navy-blue announcement bar (`Educrop X is India's #1 IFP brand — DISCIEN, H1 FY26`).
- **Floating Rounded Navigation Bar**:
  - Custom education-themed Educrop logo & brand typography.
  - Interactive dropdowns for: *Educrop X*, *Devices*, *Solutions*, *Support*, and *Partner*.
  - Call-to-action buttons: *Order Now* and *Login/Sign up*.
  - Fully responsive mobile drawer.
- **Hero Section**:
  - Centered typography:
    ```
    AI-Powered
    Connected Classroom® Device
    ```
  - Custom dark navy typography with trademark symbol.
- **Main Product Display (Interactive Flat Panel)**:
  - Realistic brushed aluminum metallic frame with camera notch and 6-microphone pinhole array.
  - Deep cyber dark interface with perspective glowing neon speed rays and horizontal grid lines.
  - Prominent **Educrop X** branding with cyan-gradient 'X'.
  - AI Prompt Pill: `Make a quiz on the water cycle` with AI sparkle badge and microphone icon.
  - 5 High-resolution application icons:
    1. Whiteboard
    2. Google
    3. EduAI
    4. Share X
    5. VisionX
  - Bottom speaker bar with centered `Educrop X` hardware branding.
- **Realistic Classroom Background**:
  - Bright, natural lighting from large multi-pane classroom window on the left.
  - Warm wooden classroom door on the right.
  - Classroom desks with two stacks of colorful textbooks (*Science, Mathematics, English, Physics, Chemistry, Geography*) at bottom right.
- **Hero CTA Buttons**:
  - *Get Started* (navy gradient button with subtle glow and hover elevation).
  - *Watch Demo* (white pill button with dark navy border).
- **Interactive Modals**:
  - Institutional Quote Request Modal for schools.
  - Teacher/School Login & Registration Modal.
  - Interactive Feature Walkthrough Demo Modal.
  - Application Preview Modal for Whiteboard, Google, EduAI, Share X, and VisionX.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
